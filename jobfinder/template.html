      GitHub access

      The token lets this page save the company list to your repository. Create it once:

      1. GitHub → your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      2. Repository access: Only select repositories → your job-shortlist repository.
      3. Permissions → Repository permissions → Contents: Read and write.
      4. Generate, copy the token and paste it here.
